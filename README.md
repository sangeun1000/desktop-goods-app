# 데스크톱 굿즈 (시제품)

설치하지 않고 실행하는 프로그램입니다. 파일을 받아 더블클릭하면 화면 왼쪽에 막대가 뜹니다.

## 내려받기
- **맥 (Apple 칩)**: [opoint-okman-digital-goods-mac.zip](https://github.com/sangeun1000/desktop-goods-app/releases/latest/download/opoint-okman-digital-goods-mac.zip) — 압축을 풀면 `[opoint]읏맨디지털굿즈` 앱이 나옵니다. 더블클릭.
- **Windows (64비트)**: [opoint-okman-digital-goods-win.zip](https://github.com/sangeun1000/desktop-goods-app/releases/latest/download/opoint-okman-digital-goods-win.zip) — 압축을 풀면 `[opoint]읏맨디지털굿즈.exe` 가 나옵니다. 더블클릭 (설치 없음).
- [읽어주세요](https://github.com/sangeun1000/desktop-goods-app/releases/latest/download/README-ko.txt)

## 처음 실행할 때 경고가 나옵니다
회사 인증서로 서명하지 않은 시제품이라 나오는 경고입니다.
- **Windows** "Windows의 PC 보호" 파란 창: **추가 정보** → **실행**
- **맥** "확인할 수 없습니다" 창: [완료]를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 **그래도 열기**. 또는 터미널에서 `xattr -cr "[opoint]읏맨디지털굿즈.app"`

새 콘텐츠는 막대의 [업데이트] 버튼으로 받습니다. 제안용 시제품입니다.
