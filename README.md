# 데스크톱 굿즈 (시제품)

설치하지 않고 실행하는 프로그램입니다. 파일을 받아 더블클릭하면 화면 왼쪽에 막대가 뜹니다.

## 내려받기
- **맥 (Apple 칩)**: [goods-mac-arm64.zip](https://github.com/sangeun1000/desktop-goods-app/releases/latest/download/goods-mac-arm64.zip) — 압축을 풀고 앱을 더블클릭
- **Windows (64비트)**: [goods-win-x64-portable.exe](https://github.com/sangeun1000/desktop-goods-app/releases/latest/download/goods-win-x64-portable.exe) — 더블클릭 (설치 없음)
- [읽어주세요](https://github.com/sangeun1000/desktop-goods-app/releases/latest/download/README-ko.txt)

## 처음 실행할 때 경고가 나오면
서명하지 않은 시제품이라 나오는 경고입니다.
- 맥: 앱을 우클릭 → 열기. 그래도 안 되면 터미널에서 `xattr -cr "읏맨 굿즈.app"`
- Windows: "Windows의 PC 보호" 창에서 추가 정보 → 실행

새 콘텐츠는 막대의 [업데이트] 버튼으로 받습니다. 제안용 시제품입니다.
